## paano palitan ang music 🎧
buksan ang index.html tapos hanapin to:
 
```html
<audio id="bgm" src="music.mp3" loop preload="metadata"></audio>
```
 
palitan lang ang music.mp3 ng file or direct mp3 link mo. note na hindi ito pwede ang link ng spotify or youtube ha, direct mp3 lang.
 
tip: need ng isang tap or click ng bisita bago mag play ang music, rule yan ng browsers hehe
